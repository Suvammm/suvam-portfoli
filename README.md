# Suvam Kurmi — Portfolio

## Add your photo
1. Put your photo in the `assets` folder.
2. Name it exactly:
   `profile.jpg`
3. Open `index.html`.

The photo area is already wired for `assets/profile.jpg`. The current placeholder is an SVG so the site works before you add your photo.

## Run locally
You can simply open `index.html` in a browser.

For a local server:
- VS Code: use Live Server
- Or run: `python3 -m http.server 8000`

Then open http://localhost:8000

## Deploy
This is a static site and can be deployed directly to Vercel, Netlify, or GitHub Pages.
